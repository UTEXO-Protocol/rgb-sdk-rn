## What changed in UniFFI

### `SdkUnlockRequest` — bitcoind fields are now optional

```diff
- bitcoind_rpc_username: string
- bitcoind_rpc_password: string
- bitcoind_rpc_host: string
- bitcoind_rpc_port: u16
+ bitcoind_rpc_username: string?
+ bitcoind_rpc_password: string?
+ bitcoind_rpc_host: string?
+ bitcoind_rpc_port: u16?
+ gossip_rgs_server_url: string?   ← new field
```

The node can now unlock using only an Esplora/Electrum `indexer_url` without bitcoind RPC.  
When both are provided, the native layer throws `AmbiguousChainBackend`. When neither is provided, it throws `MissingChainBackend`.

### `NodeInfo` — new optional field

```diff
+ latest_rgs_snapshot_timestamp: u64?
```

### New native error variants

| Variant | When thrown |
|---|---|
| `MissingChainBackend` | unlock called with no bitcoind RPC and no indexer URL |
| `AmbiguousChainBackend` | unlock called with both bitcoind RPC and indexer URL |
| `GossipUpdateFailed(String)` | RGS sync failed |
| `GossipUpdateTimeout` | RGS sync timed out |
